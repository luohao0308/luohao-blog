## 后台导入与回退

1. [内容包](portfolio-refresh-2026-11.json) 的每项包含具体字段、旧值以及核对用的线上更新时间或文章版本。如果生产版本变化，先重新读取并合并，保留上线后的更新。
2. 前端素材就绪后，用后台新建两篇草稿，slug 必须与 Markdown 文件头一致。文件头提供标题、摘要和标签，正文从第二个分隔线之后开始。检查插图、目录与互链后，再按需要公开。
3. 对 AIGC 现有文章做一次正文修订。文件头的 draft 表示交付稿状态，现有文章的公开状态、封面和标签以后台原值为准。
4. 在作品后台逐项复制 `after` 字段。机会工作台与博客各按 `screenshotFiles` 的顺序上传两张图片，目录是 `frontend/public/images/editorial/portfolio-2026-11/`。确认图片加载并能放大后保存。其余三个项目保留原截图字段。
5. 如需撤回，先重新核对当前记录，再恢复对应的 `before` 字段。新增文章可分别取消发布。AIGC 可通过文章修订历史恢复对应正文。
