# 团队运维 Runbook

本目录保存团队共同维护、可复用且经过验证的操作流程。内容进入 Git 评审；不要在此记录凭据、个人记忆、一次性命令输出或动态部署流水。

每份 Runbook 至少说明适用范围、前置条件、Preflight、操作步骤、验证、失败处理、恢复/回滚、证据入口和敏感信息边界。动态值必须标注验证时间，执行前重新核验。

部署流水、发布日志、完整命令输出和环境快照保存在受控 CI/部署平台或日志系统，并在此链接稳定的证据入口。

- [公众号同步启用与恢复](wechat-sync.md)：配置、草稿/发布/群发模式、任务恢复、回退与凭据边界。

- [域名与 HTTPS 切换](domain-cutover.md)：DNS、备案展示、Secure Cookie、微信与状态页切换及回退。

- [网站能力补齐交付与恢复](website-completion.md)：S1–S6、迁移12–15、真实邮件前提及保留数据的回退边界。
