# 小程序内容安全承接与联调

关联[契约](../../contracts/WECHAT-CONTENT-SAFETY.md)和[实施计划](../../plans/MINIPROGRAM-CONTENT-SAFETY-2026-11.md)。这是可重复流程，不包含一次性权限、镜像或用户数据。

## 当前默认与版本要求

`wechat.content_safety_enabled`默认false。新小程序只使用mini安全评论接口，不回退Web；旧0.1.0开发包没有切换这些接口，不能拿它代表安全接入后的提审候选。新候选拟用0.1.1，须重新固定源码和小程序树。

开启前确认原有正式AppID/Secret及登录开关、明确的Redis地址、`data.database.debug=false`。继续使用现有私密配置的正常loader，不读取/打印真实Secret、Redis密码或DSN；新开关单独合并，不能覆盖原凭据。专用Redis池负责context deadline和清理，不改网站共享池选项。

## 承接顺序

1. 按准确源码通过Git交付守卫、PR和required CI；核对合并树及既有release产物的原始OCI摘要，不使用latest作为身份。
2. 生产操作另获准确版本授权。先核对当前服务与覆盖链、备份DB/uploads并验证；只更新获授权的后端，迁移18→19，不重建数据服务或无变更前端。需要新配置重启时同样纳入准确动作范围。
3. 先核对隐私用途是否涵盖本文件所列实际数据流；未涵盖时由用户在正常微信后台更新对应内容，不能自动代替其提交运营承诺。平台备案/隐私/UGC状态不等于代码能力证明。
4. 正式API联调另绑定AppID、源/镜像、用户、非敏感测试文案、请求次数和期限。由用户正常微信登录得到code，后台匹配其既有绑定；不取客户端Token、不伪造站长身份或直接替他人OpenID检测。
5. 优先用一条明确标记的非敏感测试评论，包含本站公开链接可使既有本地规则保留PENDING，避免自动公开测试内容。两个scene调用和一次服务令牌获取均计入范围；真实返回review/risky或身份过期照实记录，未知结果不自动重发。测试评论按授权保留，不自动永久删除。
6. 核对该评论的已保存回执、实际检测状态/双trace与站内状态；只投影必要状态，不能输出OpenID、正文之外的身份秘密、缓存Token或上游URL/errmsg。成功的私有待审联调不冒称已跑生产公开审批闭环。
7. 新包手机回归通过、服务类目/域名、适用声明和审核登录方式核对完，再分别办理准确包的上传、提审与正式发布权限。

## 实际新增数据流与隐私核对

- 服务端向微信内容安全接口提供当前AppID的作者OpenID、评论实际存储的公开昵称快照（scene1）和评论正文（scene2）。不向该接口提供站内邮箱、密码、access/refresh token或头像。
- 服务端保存检测状态、输入摘要、追踪标识和恢复代数，用于控制小程序展示及排错。删除评论时清除检测身份引用、摘要和trace，保留最小创建幂等键及创建负载哈希，防同键网络重放重建已删内容；账号实体删除会级联清理这些关联记录。不将哈希元数据称为匿名数据，也不宣称已有自动注销/定时清理功能。
- 小程序本机按账号/文章保存未完成评论的正文和提交标识，用于防丢稿及重试找回；不在新缓存中保存wx.login code或Token。发送确认或用户改正文时更新/清理匹配的意图，换账号不展示其他账号的内容。

以上是实现事实和核对材料，不应不经用户检查就直接改写现有隐私指引；已覆盖的内容无需重复提交。

## 结果、诊断与停止

只有双场景pass且站内APPROVED、当前身份/输入证据一致的评论在mini投影公开。网站普通批准不改微信pass，作者重检不自动跳过站内审批；已通过内容读取不需要重复发送微信。

诊断只记录固定阶段与数值错误码，不记录私密errmsg或请求URL。61010代表近两小时访问条件，不以强刷服务令牌解决；87014保持风险终态；无效服务令牌仅比较后清旧缓存，不自动重放检测请求。检查上游配置错误时不能为诊断打印Token/Secret。

迁移dirty、备份、正式调用结果或关键冒烟未知/失败即停止。数据库19后不能直接切回不含19迁移源的旧18后端；保持兼容19的版本并关闭新检测可停止新调用，未检查内容不会因此放行。不得down/force或覆盖数据库掩盖失败，数据恢复须针对准确备份另获授权。

微信后台网址的电脑控制已被工具禁止，不通过换浏览器或直接请求其后台接口绕过；平台信息由用户在正常页面提供。
